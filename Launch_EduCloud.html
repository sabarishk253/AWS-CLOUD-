AWS Amplify Drag & Drop Deployment

Deploy EduCloud to the cloud without configuring Git or build scripts:

  1. Locate amplify_deploy.zip in the project folder.
  2. Open AWS Amplify Console and click Create new app.
  3. Select Deploy without Git provider (Manual deployment).
  4. Enter your App name (e.g. EduCloud) and branch (main).
  5. Drag and drop amplify_deploy.zip into the upload area.
  6. Click Save and deploy. Your static site is live with HTTPS in seconds!
